# 💜 Capsule

Aplicación web (PWA) para documentar y celebrar momentos de pareja.

## 🚀 Stack

- **Frontend:** React + Vite
- **Backend:** Firebase (Firestore, Storage, Auth, Functions)
- **Hosting:** Vercel
- **Animaciones:** Framer Motion

## 📅 Roadmap

- **14 Feb 2026:** Teaser (carta digital interactiva)
- **4 Abr 2026:** Lanzamiento completo con Wrapped del Año 4

## 🛠️ Desarrollo

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
npm run preview
```
